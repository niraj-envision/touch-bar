# Repository instructions

- Treat this repository as the canonical source for the installed Omarchy
  Touch Bar project.
- After changing the project, validate Python and TOML syntax and perform a
  proportionate live verification when the Touch Bar hardware is available.
- Keep raw-touch workspace controls independent from microphone controls and
  preserve a stable 13-button `tiny-dfr` layout.
- Do not commit generated SVGs, runtime state, credentials, session logs, or
  local backup files.
- When a requested edit is complete and verified, commit it and push the
  current branch to `origin` unless the user explicitly says not to push.
